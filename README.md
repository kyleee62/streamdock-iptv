# StreamDock IPTV

Free, ad-free, local IPTV player (Xtream Codes and M3U).

**Download:** see [Releases](https://github.com/kyleee62/streamdock-iptv/releases/latest).

- Windows: `StreamDock-IPTV-Setup-<version>.exe` (installs and updates itself) or `StreamDock-IPTV-Portable-<version>.exe`
- Android phones, tablets and TVs: `StreamDock-IPTV-Android-<version>.apk`

The app is not code-signed, so Windows may show "Windows protected your PC": click **More info -> Run anyway**.
